# AviUtl2 レイヤー一括切り替えプラグイン
複数レイヤーの表示状態、ロック状態をドラッグ操作で一括に切り替えられるようになる AviUtl2 プラグインです。  
sigma-axis さんの [レイヤー一括切り替えプラグイン](https://github.com/sigma-axis/aviutl_toggle_layers) の AviUtl2 向け移植版です！

## 導入方法（自動・おすすめ）
https://aviutl2-catalog-badge.sevenc7c.workers.dev/package/Garech.ToggleLayers

上記のリンクにアクセスするとAviUtl2 カタログでの当プラグイン紹介ページを開けます。<br>
画面右下辺りの`インストール`ボタンからダウンロード・インストールできます。

> [!NOTE]
> [AviUtl2 カタログ](https://github.com/Neosku/aviutl2-catalog/releases/latest) をインストールしている必要があります。

## 導入方法（手動）
https://github.com/Garech-mas/AviUtl2_toggle_layers/releases/latest

上記のリンクにアクセスした後、`AviUtl2_toggle_layers_v2.XX.au2pkg.zip` からダウンロードできます。

AviUtl2を起動し、ダウンロードしたZIPファイルをプレビュー画面にドラッグ＆ドロップすることで導入できます。 

## 導入時の注意点
- 必ず最新バージョンのAviUtl2を導入してください。
<br>**必須バージョン以下の場合、プラグインが認識されない・使用できない場合があります。**
- 設定ファイルの記載によっては、**通常動作が不安定になることがあります。** 詳しくは後述。

## 使い方
初期設定は以下の操作に割り当てられています。設定ファイルで他の操作に変更することもできます。
- `Alt` + 左クリックドラッグで、カーソルが通った範囲をすべて表示 / 非表示にできます。
- `Shift` + 左クリックドラッグで、カーソルが通った範囲のロック / ロック解除が切り替わります。

## 設定ファイル
`toggle_layers.ini` ファイルをテキストエディタで編集することで、キーの組み合わせとマウス操作に対する動作を割り当てることができます。  
※詳しくはファイル内のコメントを確認してください。
- マウス操作は `L` (左ボタン), `R` (右ボタン), `M` (中央ボタン), `X1` (拡張ボタン1), `X2` (拡張ボタン2) の5種類から選べます。
- 装飾キーは `Ctrl` / `Shift` / `Alt` の組み合わせから選べます。
- 同じ動作を複数割り当てることも可能です。設定しない場合は AviUtl2 のデフォルト動作が実行されます。

### 使用時の注意点
AviUtl2 の仕様や SDK の限界により、以下の制約があります。
- １レイヤーの動作ごとに Undo 履歴が作成されるため、「元に戻す」操作の履歴数に注意してください。
- プレビュー再生中に、タイムライン上で修飾キーを含んだクリック操作を行う際、オプションに係わらず `停止` もしくは `クリックした位置へ移動` 扱いになります。
- シーン切り替えボタン、レイヤー拡大率変更ゲージ部分で、設定されたドラッグ操作を行う際、隣接したレイヤーの操作が優先されます。
  - 修飾キーなしの `L` ボタンを割り当てた場合、スクロールバー横にあるゲージ部分を左クリックドラッグして `レイヤー表示の拡大率変更` が行えなくなります。
  - このプラグインで割り当てていない修飾キーを含みながら左クリックドラッグすることで回避できます。
- `Shift` キーを割り当てた場合、プレビュー再生中に切り替えを行った際に意図せずフレーム範囲選択されてしまいます。
  - `共通操作の設定` から、`フレーム移動時の範囲選択` をしない設定にすることで回避できます。
